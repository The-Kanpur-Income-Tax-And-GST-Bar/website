# The Kanpur Income Tax and GST Bar Association (Regd.): website

Bilingual (English + हिन्दी) static site, built with [Astro](https://astro.build) and published on GitHub Pages.

```sh
npm install
npm run dev      # http://localhost:4321/
npm run build    # type-checks content, then builds to dist/
```

- **Updating content** (notices, events, committee, press): see [`CLAUDE.md`](CLAUDE.md). It is written so a Claude Code session can follow it.
- **Roadmap and decisions:** see [`PLAN.md`](PLAN.md).
- Pushing to `main` deploys automatically. The site also rebuilds daily so past events move out of "Upcoming".
